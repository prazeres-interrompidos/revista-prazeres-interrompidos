Publicação online

Edição online por ligar.

Para publicar, use uma autorização GitHub limitada ao repositório revista-prazeres-interrompidos, com a permissão Contents: Read and write.

A autorização fica apenas na memória desta janela e é enviada diretamente ao GitHub. Não a coloque nos textos nem a envie numa conversa.

Como obter a autorização
  1. Abra Criar autorização no GitHub ↗.
  2. Escolha uma data de validade e o proprietário prazeres-interrompidos.
  3. Em Repository access, escolha Only select repositories e selecione apenas revista-prazeres-interrompidos.
  4. Em Repository permissions, defina Contents como Read and write. Mantenha as restantes permissões sem acesso adicional.
  5. Crie a autorização, copie-a e cole-a no campo protegido acima.

Quando ativa, publica após 90 segundos sem alterações, com intervalo mínimo de 6 minutos. Pode usar «Guardar e atualizar revista» a qualquer momento. A publicação do GitHub Pages demora alguns minutos.

Identificação e capa

As edições anteriores são mantidas. Guarde também uma cópia JSON para ter uma cópia de segurança independente. Os rascunhos automáticos pertencem apenas a este navegador; o conteúdo publicado fica disponível online.
